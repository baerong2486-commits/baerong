## 셋업 순서

### ① Supabase — 순서 주의
1. New project 생성 (한 프로젝트 = 한 사람)
2. Settings → API 에서 `Project URL` 과 `anon public` 키 복사
3. **Authentication → Users → Add user** 로 관리자 계정 생성
   (이메일·비밀번호 입력, **Auto Confirm User 켜기**)
4. SQL Editor 에 `supabase_setup.sql` 전체를 붙여넣고 **Run**
   (여러 번 다시 실행해도 데이터가 지워지지 않습니다)

⚠️ **3번을 먼저, 4번을 나중에.** 순서를 바꾸면 쓰기 권한이 잠겨 관리자에서 저장할 수 없습니다.

### ② supabase.js 상단 2줄 교체
```js
const SUPABASE_URL  = 'https://xxxxxxxx.supabase.co';
const SUPABASE_ANON = 'eyJhbGciOi....';
```

폴더 구조 그대로 올립니다. `fx.js` · `site.js` · `fxfb.js` · `style.css` 는 **루트**,

월·목 자동으로 한 번씩 핑을 보냅니다.

### ⑥ SOOP 게시글 삽입

페이지마다 높이를 따로 적습니다. SOOP은 높이 자동조절 신호를 듣지 않으므로
**한 값만 적어야 하면 표에서 가장 큰 값**을 쓰세요 (여백이 스크롤 두 개보다 낫습니다).

```html
<iframe height="여기에 아래 표의 값" scrolling="no" src="배포주소"
        style="width:100%;border:0;display:block;"></iframe>
```

| 페이지 | 임베드 폭 1000~1100 | 좁은 폭(모바일) | 한 값만 쓸 때 |
|---|---|---|---|
| 메인 | 850 | 950 | **1030** |
| 프로필 | 2100 | 2950 | **2950** |
| 일정 | 1780 | 1880 | **1880** |
| 공지 | 850 | 850 | **850** |
| 업보 | 850 | 850 | **850** |
| 옷장 | 880 | 890 | **890** |

공지·업보·옷장은 등록한 항목 수에 따라 늘어납니다. 항목을 많이 넣었다면
배포된 페이지에서 F12 → 콘솔에 `document.documentElement.scrollHeight` 를 입력해
나온 값 + 50 을 쓰세요.

메인은 16:9 비율로 고정돼 있어 iframe 높이를 크게 줘도 사진이 늘어나지 않고
아래쪽에 여백만 생깁니다.

## 관리자 로그인 · 권한

- 로그인은 **Supabase Auth**. 코드에 비밀번호가 들어가지 않습니다.
- 계정 추가·비밀번호 변경·관리자 제외는 전부 **Supabase → Authentication → Users** 에서 처리
- 세션은 Supabase가 보관하므로 새로고침해도 유지. 로그아웃 버튼은 관리자 화면 상단
- 권한은 DB(RLS)에서 나눕니다

| 동작 | 누가 |
|---|---|
| 사이트 표시(읽기) | 누구나 |
| 등록·수정·삭제 | 로그인한 관리자만 |
| 문의 보내기 | 누구나 |
| **문의 읽기** | **관리자만** (개인정보) |

### 자주 쓰는 규격
- **생일** `MM.DD` (예: `08.18`) → D-Day 자동
- **데뷔일** `YYYY.MM.DD` (예: `2024.09.23`) → D-Day + 주년 자동
- **능력치** 한 줄에 `이름:숫자` (0~100). 줄을 늘리면 항목이 늘어납니다
- **TMI / 프로필 추가 항목** 한 줄에 `항목이름:내용`. 항목 이름도 자유
- **일정 하이라이트** 체크하면 달력에 분홍 점선 테두리 + ♥ 표시
- **목표** 한 줄에 `상태|내용`. 상태가 `달성`이면 취소선
- **등록한 항목 수정** 공지 · 일정 · 옷장 · 다시보기 목록의 `수정` 버튼 → 위 입력칸에 값이 채워짐 → `수정 저장`
- **배경 사진** 🌸 사이트 탭에서 이미지 주소만 넣으면 메인·전 페이지가 한 번에 바뀜.
  인물이 잘리면 **사진 위치**, 글씨가 안 읽히면 **사진 연하게(0~100)** 조절
- **옷장 사진** 세로 3:4 (900×1200 권장)
- **이미지 넣는 법** SOOP 비공개 게시판에 올린 뒤 이미지 **우클릭 → “이미지 주소 복사”**
  (게시글 주소 ✗ / `https://stimg.sooplive.com/…` 형태가 맞습니다)

## 디자인 메모

- 컨셉 : **꽃 일기장** — 각 페이지가 다이어리에서 뜯어낸 한 장 (VOL. 01~05 넘버링)
- 종이 결(가로줄) · 마스킹 테이프 · 점선 · 포스트잇 · 손글씨 낙서
- 글머리표와 클릭 입자는 **픽셀(도트) 하트** — 마인크래프트/도트 감성
- 폰트 : Gamja Flower(이름) · Hi Melody(손글씨) · Noto Sans KR(본문, 굵기 4종)
- 색 : 메인 `#F5D7E2` / 서브 `#E3E3E3` 기준 파스텔 팔레트 (관리자에서 변경 가능)
- 상단바는 **마스킹 테이프** — 전 페이지 동일 마크업이라 페이지를 옮겨도 헤더가 튀지 않습니다
- 메인 커버는 **16:9 비율 고정** — SOOP 게시글이 주는 iframe 높이에 사진이 끌려가지 않습니다
- 모바일 크기는 전부 **폭 기준** — SOOP 앱이 주는 큰 iframe 높이에도 사진이 늘어나지 않습니다
- 임베드 안에서는 모달이 **누른 위치 근처**에 뜹니다 (박스 중앙에 떠서 사라지는 문제 방지)
- 화면에 보이는 글자는 **로고 · 머리말 · 섹션 이름 · 푸터 · 모달까지 전부 관리자에서 수정 가능**
- 다크모드는 `localStorage` 에 저장돼 페이지를 옮겨도 유지됩니다
